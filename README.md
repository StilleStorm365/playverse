# Playverse

A public browser portal for AI-made 2D/3D minigames, levels and quests. Low budget, highscores early, multiplayer later. Separate from Little Copenhagen.

## Status
No code yet. Version 1 (approved 12 Nov 2026): a small 2D level race where each level is a JSON file, a nickname-only leaderboard per level and version, an English UI, and proposals from the owner only, reviewed as pull requests.

## Docs (Danish)
- `docs/foerste-minispil.md`: scope of the first minigame (approved)
- `docs/teknisk-skitse.md`: technical sketch (Cloudflare Pages + D1, versioned levels, rollback, CI validation)
- `docs/hub-og-portaler.md`: research on a hub world with portals and sandboxed creator code (not decided)

Decisions and status live in the project folder (`Projektmappe/playverse/README.md`); the docs here are copies from 12 Nov 2026.
